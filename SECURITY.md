# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes (current pre-beta) |
| < 0.2   | No |

## Reporting a Vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub Security Advisories:
https://github.com/cyberkiwi/cyberkiwi-client/security/advisories/new

Include:
1. A short summary and the affected component (for example `server.ts`, `server/netSafety.ts`, or a client build).
2. Reproduction steps and the version or commit.
3. Your assessment of impact.

We will acknowledge receipt, confirm the issue, and coordinate a fix and release. Please give us reasonable time to respond before any public disclosure.
