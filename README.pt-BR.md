# CyberKiwi

O CyberKiwi é um cliente de inteligência de notícias de cibersegurança: agrega feeds de segurança, agrupa a cobertura duplicada em histórias e oferece modo leitura e resumos com IA.

> **Esta versão em português não é mais mantida.** A documentação atual — status do projeto, requisitos (Node.js 22+), configuração, banco de dados, contas por convite e modelo de acesso — está no [README em inglês](README.md).
